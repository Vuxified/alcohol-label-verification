Check many labels

Check a whole batch at once

Add one ZIP file with the label pictures and one spreadsheet (CSV) with a row per application. We check them all, show what needs attention first, and give you a results spreadsheet.

No files handy?

Download a sample batch (22 applications; the spreadsheet is inside the ZIP), then add it below. Two of its rows are broken on purpose, to show that one bad row doesn't stop the rest.

Up to 500 applications per batch; each can have up to 6 pictures (front, back, neck…). JPG, PNG or WEBP, up to 20 MB each. Any file names. If the ZIP contains manifest.csv, you can skip this.
Nothing is checked until you confirm on the next step.

Pictures can have any file names

We read each picture and match it to its spreadsheet row by brand, alcohol and net contents. A picture is matched only when one row clearly fits; any we can't match for sure are listed for you to match by hand, never guessed.

Tip: name pictures after the application (TTB-0001_front.jpg) and they're always matched, with no reading needed.

What the spreadsheet needs

A header row, then one row per application. Column names are not case-sensitive, and common names work too ("Brand Name", "Application ID", "Images").

ColumnNeeded?Example
application_idYes, uniqueTTB-0001
beverage_typeNo (told from the label when blank)spirits, wine, or malt (beer is accepted)
brand_nameYesOld Tom Distillery
class_type, abv, net_contents, name_address, fanciful_nameNoKentucky Straight Bourbon Whiskey · 45 · 750 mL
source, country_of_originNoimported · Mexico (source defaults to domestic)
label_heightNo3.5 (inches, the label with the health warning; lets the warning's type size be checked)

Advanced: to choose the pictures for a row yourself, add an image_files column listing its file names, separated by ; (0001_front.jpg;0001_back.jpg).
